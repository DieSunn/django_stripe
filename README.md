# Django + Stripe Payment Service

Тестовое задание на реализацию интеграции Django с платежной системой Stripe. 
Сервис позволяет просматривать товары и заказы, а также оплачивать их через Stripe Checkout Session.

## Функционал

### Основное задание:
- Модель `Item` (name, description, price).
- API метод `GET /buy/{id}` для получения Session ID.
- Страница `GET /item/{id}` с кнопкой "Buy" и JS-логикой редиректа.
- Использование Python библиотеки `stripe`.

### Бонусные задачи (реализованы):
- **Docker & Docker Compose**: Полная контейнеризация приложения.
- **Environment Variables**: Конфигурация через файл `.env`.
- **Django Admin**: Просмотр и управление моделями через админку.
- **Модель Order**: Объединение нескольких товаров в один заказ.
- **Модели Discount & Tax**: Привязка скидок и налогов к заказу, передача их в Stripe (динамический расчет итоговой суммы на стороне Stripe).
- **Мультивалютность**: Поле `currency` у модели Item.
- **UI**: Главная страница со списком товаров и заказов, страницы успешной оплаты и отмены.

## 🚀 Запуск проекта

### Предварительная подготовка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/diesunn/django_stripe
   cd django_stripe
   ```

2. Создайте файл `.env` в корне проекта и заполните его (пример ниже):
   ```bash
   # .env
   DEBUG=True
   SECRET_KEY=django-insecure-your-secret-key
   ALLOWED_HOSTS=localhost,127.0.0.1,[::1]

   # Ключи Stripe (взять на https://dashboard.stripe.com/test/apikeys)
   STRIPE_PUBLIC_KEY=pk_test_...
   STRIPE_SECRET_KEY=sk_test_...
   ```

---

### Вариант 1: Запуск через Docker (Рекомендуется)

Убедитесь, что у вас установлен Docker и Docker Compose.

1. Соберите и запустите контейнеры:
   ```bash
   docker-compose up -d --build
   ```

2. Создайте суперпользователя для доступа в админку:
   ```bash
   docker-compose exec web python manage.py createsuperuser
   ```

3. Приложение доступно по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

---

### Вариант 2: Локальный запуск (без Docker)

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/Mac:
   source venv/bin/activate
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Примените миграции:
   ```bash
   python manage.py migrate
   ```

4. Создайте суперпользователя:
   ```bash
   python manage.py createsuperuser
   ```

5. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

## 🧪 Инструкция по тестированию

### 1. Заполнение данными (Admin Panel)
Перейдите по адресу [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/) и войдите под созданным суперпользователем.

1. **Создайте Товар (Item):**
   - Укажите название, описание.
   - Цена указывается в *центах/копейках* (например, 1000 = 10.00 USD).
   - Валюта: `usd` (или `eur`).

2. **Создайте Налог (Tax):**
   - Например: Название "НДС", Ставка `20.00`.

3. **Создайте Скидку (Discount):**
   - Например: Название "New Year", Процент `10`.

4. **Создайте Заказ (Order):**
   - Выберите созданную Скидку и Налог.
   - Сохраните заказ.
   - Внутри заказа добавьте товары в таблицу "Items".

### 2. Покупка
Перейдите на главную страницу [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

- **Покупка товара (Item):**
  1. Нажмите "Смотреть и Купить" напротив товара.
  2. Нажмите кнопку "Купить".
  3. Вы будете перенаправлены на форму Stripe.

- **Оплата заказа (Order):**
  1. Нажмите "Оплатить заказ" напротив номера заказа.
  2. На странице заказа вы увидите расчет стоимости с учетом налогов и скидок.
  3. Нажмите "Оплатить Заказ".
  4. В форме Stripe сумма будет пересчитана: `(Сумма товаров - Скидка) + Налог`.

### 3. Тестовые карты Stripe
Для успешной оплаты используйте тестовые данные:
- **Номер карты:** `4242 4242 4242 4242`
- **Срок:** Любая дата в будущем.
- **CVC:** Любые 3 цифры.
